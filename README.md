# LearnRoadSign
Projet TP - Introduction à l'IA :Étude comparative d'architectures de réseaux de neurones (Dense vs CNN) pour la classification de panneaux de signalisation. Inclut l'analyse de l'impact du prétraitement d'image (CLAHE) et de la régularisation par Dropout sur la robustesse des modèles.

Nous allons utiliser les données suivantes :

1. Extrait du dataset (archive.zip) https://drive.google.com/file/d/1r7mW-X_pFU74Xa3F4u0f4GRFdn7b_NHg/view?usp=sharing

2. Quelques images pour tester (test.zip) https://drive.google.com/file/d/1lU51IeKpVvxlMFWMOF3RU-K91nhAopDf/view?usp=sharing
